# Startup Landing Page

A responsive startup landing page created using HTML and CSS based on the provided Figma design.

## Features

- Sticky navigation bar
- Startup landing page
- Jeff Bezos image section
- Home navigation
- About Us navigation
- Contact Us navigation
- Contact form with custom input fields
- Input focus without the default blue outline
- Contact form submission
- Login page
- Signup page
- Navigation between Login, Signup, and Home pages
- Responsive design
- Startup information table
- Table footer implemented using the HTML `<tfoot>` element
- Montserrat font from Google Fonts

## Technologies Used

- HTML5
- CSS3
- Google Fonts – Montserrat
